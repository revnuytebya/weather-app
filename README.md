# Weather App

Консольное приложение на Python для получения текущей погоды и прогноза на 7 дней по названию города с использованием [Open-Meteo API](https://open-meteo.com/).

## Возможности

- Поиск города по названию
- Получение географических координат
- Отображение текущей температуры
- Получение скорости ветра
- Отображение времени обновления погоды
- Прогноз погоды на 7 дней
- Описание погодных условий
- Проверка корректности полученных данных
- Обработка ошибок API, подключения и тайм-аутов

## Используемые технологии

- Python 3.13
- Requests
- Open-Meteo API
- Unittest
- Unittest.mock
- Ruff

## Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/revnuytebya/weather-app.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd weather-app
   ```

3. Создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

4. Активируйте его в Windows:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

5. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

6. Запустите приложение:

   ```bash
   python main.py
   ```

## Тестирование

Запуск автоматических тестов:

```bash
python -m unittest -v
```

Тесты проверяют:

- Поиск координат города
- Получение текущей погоды
- Получение прогноза
- Проверку и обработку некорректных данных
- Обработку ошибок запросов
- Работу основной логики приложения

## Проверка качества кода

Проверка Ruff:

```bash
ruff check .
```

Проверка форматирования:

```bash
ruff format --check .
```

## Покрытие тестами

Для создания отчёта установите Coverage:

```bash
pip install coverage
```

Запустите тесты с измерением покрытия:

```bash
coverage run -m unittest
coverage report -m
coverage html
```

HTML-отчёт появится в папке `htmlcov/`.

## Источник данных
