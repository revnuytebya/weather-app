# Weather App

Консольное приложение на Python для получения текущей погоды по названию города.

## Возможности

- Поиск города по названию
- Получение текущей температуры
- Получение скорости ветра
- Отображение времени обновления погоды
- Обработка ошибок подключения
- Обработка ситуаций, когда город не найден

## Используемые технологии

- Python
- Requests
- Open-Meteo API
