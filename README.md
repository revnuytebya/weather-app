# Weather App

Консольное приложение на Python для получения текущей погоды по названию города с использованием Open-Meteo API.

## Возможности

- Поиск города по названию
- Получение текущей температуры
- Получение скорости ветра
- Отображение времени обновления погоды
- Обработка ошибок подключения и тайм-аутов
- Обработка ситуаций, когда город не найден или данные погоды недоступны
- Проверка корректности полученных данных

## Используемые технологии

- Python 3.13
- Requests
- Open-Meteo API
- Unittest
- Unittest.mock
- Ruff

## Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/revnuytebya/weather-app.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd weather-app
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```bash
   python main.py
   ```

## Пример работы

```text
Введите город: Москва

Город: Москва
Широта: 55.76
Долгота: 37.62
Температура: 10.5°C
Скорость ветра: 15.2 км/ч
Время обновления: 07.11.2026 | 12:00
```

## Тестирование

Для запуска автоматических тестов выполните:

```bash
python -m unittest -v
```

Тесты написаны с использованием `unittest` и `unittest.mock`.

Они проверяют:

- Поиск координат города
- Получение текущей погоды
- Обработку ошибок запросов
- Обработку отсутствующих данных
- Работу основной функции приложения

## Проверка качества кода

Проверка Ruff:

```bash
ruff check .
```

Проверка форматирования:

```bash
ruff format --check .
```

## Источник данных

Данные о погоде предоставляются сервисом [Open-Meteo](https://open-meteo.com/).
