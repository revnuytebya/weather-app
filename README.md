# Weather App

Консольное приложение на Python для получения текущей погоды и прогноза на 7 дней по названию города с использованием [Open-Meteo API](https://open-meteo.com/).

## Возможности

- Поиск города по названию
- Получение географических координат
- Отображение текущей температуры и скорости ветра
- Отображение времени обновления погоды
- Прогноз погоды на 7 дней
- Описание погодных условий
- Проверка корректности полученных данных
- Обработка ошибок API, подключения и тайм-аутов
- Кэширование погодных данных на 10 минут для сокращения количества API-запросов

## Используемые технологии

- Python 3.13
- Requests
- Open-Meteo API
- Unittest и Unittest.mock
- Ruff
- GitHub Actions

## Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/revnuytebya/weather-app.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd weather-app
   ```

3. Создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

4. Активируйте его в Windows:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

5. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   pip install ruff
   ```

6. Запустите приложение:

   ```bash
   python main.py
   ```

## Кэширование

Приложение сохраняет погодные данные в локальный файл `cache.json`.

- Кэш хранится отдельно для каждого города.
- Срок действия данных — 10 минут.
- При повторном запросе города актуальные данные берутся из кэша.
- После истечения срока действия данные запрашиваются заново.
- Файл `cache.json` не добавляется в Git.

## Тестирование

Запуск автоматических тестов:

```bash
python -m unittest -v
```

Тесты проверяют:

- Поиск координат города
- Получение текущей погоды
- Получение прогноза
- Проверку и обработку некорректных данных
- Обработку ошибок запросов
- Работу основной логики приложения
- Загрузку и сохранение кэша
- Проверку срока действия кэшированных данных
- Обработку повреждённых данных кэша

Всего 95 автоматических тестов.

## Проверка качества кода

Проверка Ruff:

```bash
ruff check .
```

Проверка форматирования:

```bash
ruff format --check .
```

## Автоматические проверки

GitHub Actions автоматически запускает проверки при каждом push и pull request:

- Проверка кода с помощью Ruff
- Проверка форматирования
- Запуск всех автоматических тестов

## Покрытие тестами

Для создания отчёта установите Coverage:

```bash
pip install coverage
```

Запустите тесты с измерением покрытия:

```bash
coverage run -m unittest
coverage report -m
coverage html
```

HTML-отчёт появится в папке `htmlcov/`.
